# Quick Palindrome Checker

A super‑lightweight CLI tool that checks whether the provided input string is a palindrome (ignoring case, spaces, and punctuation).

## Usage
```bash
python palindrome.py "A man, a plan, a canal: Panama"
```
Output:
```
✅ "A man, a plan, a canal: Panama" is a palindrome!
```

## Installation
Just clone the repo and run the script; no external libraries are required.

## Options
- **No arguments** – reads from STDIN line by line.
- **One argument** – checks that argument directly.
